نسخة مبسطة من موقع Free Fire Clash Squad
========================================

الملفات:
- index.html  صفحة الموقع
- style.css   التصميم والألوان
- script.js   التسجيل التجريبي والتفاعلات
- README.txt  تعليمات التشغيل

طريقة التشغيل:
1. ضع الملفات الأربعة في نفس المكان.
2. افتح index.html مباشرة في المتصفح.

دخول المشرفين:
- اسم المستخدم: admin
- كلمة المرور: 2367305746

من لوحة المشرفين تستطيع:
- إضافة الفرق واللاعبين.
- إضافة المواجهات واختيار الفريقين.
- تحديد تاريخ وساعة المباراة والخريطة والجولة.
- حذف فريق أو مواجهة.
- تصفير جميع البيانات والبدء من جديد.

ملاحظات:
- لا تحتاج هذه النسخة إلى Node.js أو قاعدة بيانات.
- البيانات تحفظ في localStorage داخل المتصفح فقط.
- هذه نسخة تجريبية محلية؛ غيّر بيانات الدخول داخل script.js إذا أردت.
